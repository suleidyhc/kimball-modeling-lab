📌 Descripción
Este repositorio es un laboratorio dedicado al diseño y desarrollo de modelos dimensionales bajo la metodología Kimball, integrando buenas prácticas de Data Engineering con herramientas modernas como Databricks, Microsoft Fabric, dbt, Delta Lake y Power BI.

🎯 Objetivo del repositorio
Practicar modelado dimensional (Kimball)
Documentar buenas prácticas de ingeniería de datos
Construir casos de uso reales (ventas, inventario, clientes, logística)
Justificar certificaciones profesionales mediante ejemplos prácticos
Publicar contenido técnico y educativo

📁 Estructura del repositorio

templates/   → Plantillas reutilizables

📌 Description
This repository is a laboratory dedicated to the design and development of dimensional data models using the Kimball methodology, integrating modern Data Engineering best practices with tools such as Databricks, Microsoft Fabric, dbt, Delta Lake, and Power BI.

🎯 Repository Purpose
Practice dimensional modeling (Kimball)
Document data engineering best practices
Build real-world use cases (sales, inventory, customers, logistics)
Justify professional certifications through practical examples
Publish technical and educational content

📁 Repository Structure
docs/        → Conceptual documentation
templates/   → Reusable templates
src/         → SQL, PySpark, Fabric, dbt code
examples/    → Real-world use cases
metadata/    → Glossary and business rules
README.md    → This document

🧩 Included Use Cases
Sales model (DimCustomer, DimProduct, FactSales)
Inventory model
Customer model
Logistics model

🛠️ Technologies Used
Databricks (Delta Lake, PySpark)
Microsoft Fabric (Lakehouse, Warehouse)
dbt (staging, marts, tests)
